# Product

## Register

product

## Users

People on Omarchy create, edit, and present Markdown decks. They open a
Markdown file, use the editor and preview, and start a presentation.

## Product Purpose

Omapresent is a dead-simple, Markdown-only presentation app for Omarchy. A
Markdown file is already a presentation. The writing structure is the deck.

## Brand Personality

Minimal, simple, keyboard-first.

## Anti-references

Do not add styling controls, slide masters, layout fiddling, or color and font
dials. Do not shrink text to make it fit.

## Design Principles

- Keep Markdown as the source of truth.
- Use the current Omarchy theme without per-document styling knobs.
- Preserve full text size. Let content scroll rather than compress.
- Support keyboard operation and the desktop text scale.

## Accessibility & Inclusion

Keep keyboard shortcuts and keyboard navigation available. Follow the desktop
text scale. Keep the audience text and background at the specified
WCAG-AA-ish contrast floor.
