## The local package is validation-only

`makepkg` run here produces `pkgbuild/omapresent-<ver>-1-x86_64.pkg.tar.zst`.
That artifact proves the PKGBUILD builds and passes `namcap`. It is **not** a
release asset and must never be uploaded.

Its `.BUILDINFO` records this host's build environment — the exact installed
package set, build directory and toolchain of whoever ran it — so publishing it
would ship one developer's machine state as the official binary and make the
asset unreproducible by anyone else. `.gitignore` already excludes
`*.pkg.tar.*`; leave the file where it is and simply never select it.

The published asset is built by the Release workflow on the release event, from
the immutable tag archive and the verified checksum, and attached from there.

## Hard stop

**Preparation only.** Do not tag, do not push, do not create a GitHub release,
and do not touch the Omarchy package fork or PR #235. The release commit is
staged locally and waits for a separate go-ahead.

## Required work

1. Verify every release-note claim against `git log v0.1.1..HEAD` and the
   tests that cover it. Claims that no commit in that range supports are
   dropped, not softened.
2. Bump `pkgver` to `0.1.2` in both PKGBUILDs and reset the source checksum
   to the zero placeholder. The real checksum cannot exist until the tag is
   pushed, because a tag archive contains the PKGBUILD that would hash it —
   `v0.1.0` and `v0.1.1` both shipped this way.
3. Write `.github/release-notes/v0.1.2.md`.
4. Run the full gate:
   `QT_QPA_PLATFORMTHEME= QT_STYLE_OVERRIDE=Fusion ./bin/build` then
   `QT_QPA_PLATFORMTHEME= QT_STYLE_OVERRIDE=Fusion ./bin/test`.
5. Build the package with the repository's existing scripts and record the
   SHA-256 of every staged asset.
6. Append factual start and finish entries to `worklog.md`.

## Done when

Both PKGBUILDs read `0.1.2` with the placeholder checksum, the notes exist and
every line in them is backed by a commit, the gate is green, the package builds,
the asset hashes are recorded, and nothing has been tagged, pushed or published.
